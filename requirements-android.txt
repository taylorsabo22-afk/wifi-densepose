# Android / Termux compatible requirements for WiFi-DensePose
#
# Install on Termux with:
#   pkg install python python-numpy python-scipy libzmq clang
#   pip install -r requirements-android.txt
#
# Notes:
#  - opencv-python-headless is used instead of opencv-python (no display needed)
#  - torch/torchvision are heavy; install pre-built ARM wheels when available,
#    or skip and use the CPU-only stub in src/core/pose_estimator.py
#  - asyncssh is optional; SSH router interface falls back gracefully when absent
#  - psycopg2-binary is replaced by the pure-Python aiosqlite fallback
#  - scapy requires root on Android; it is listed as optional
#  - redis / celery are optional; the app runs without them using SQLite fallback
